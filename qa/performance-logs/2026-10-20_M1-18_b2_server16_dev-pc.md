Date: 2026-10-20 · Machine: dev-pc (`machines/dev-pc.json`), Docker Desktop 29.6.2 (WSL 2) · Build: `4537745` (Debug image, as for the dev server) · Seed: server world 0x53570001, bots 0xB0752 + i
Command: `scripts/run-b2.sh` (from `source/`). Raw data: `2026-10-20_B2_4537745_dev-pc/` (`summary.json`, `ticks.csv` with 18,000 ticks, event logs).
Setup (M0-07 A1/A5): headless server container limited to 4 CPUs / 8 GB with 200 creatures; 16 ENet bot clients in a second container replaying recorded inputs and offering Pacts every 10 s. Both containers shape outgoing traffic with `tc netem delay 75ms loss 2%`, so the round trip is 150 ms with 2% loss each way. Measuring starts when all 16 bots are in, followed by 900 warm-up ticks (30 s); then 18,000 ticks (10 min) are measured.
